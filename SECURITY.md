# Security Policy

Если найдена уязвимость, **не публикуй** в Issues действующие cookies, токены, пароли или приватные URL.

При включённых приватных уведомлениях воспользуйся [GitHub Security Advisories](https://github.com/hvhonelove/LinkGrabAndroid/security/advisories) → **Report a vulnerability**. Если этот механизм недоступен, создай общее issue без подробностей эксплуатации и запроси закрытый канал связи.

Поддерживаются актуальная ветка `main` и последний preview-релиз в GitHub Releases. Старые сборки могут содержать исправленные ошибки.
