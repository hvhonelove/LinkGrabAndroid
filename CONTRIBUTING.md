# Участие в разработке / Contributing

Спасибо, что хочешь помочь LinkGrab! Проект доступен под **GNU GPL-3.0-only**.

## Нашёл ошибку?

Проверь [существующие Issues](https://github.com/hvhonelove/LinkGrabAndroid/issues), затем создай новый отчёт:

- Версия LinkGrab и Android.
- Устройство (например, Samsung Galaxy S25 Ultra).
- Публичная ссылка на ролик, если проблема связана с конкретным сайтом.
- Шаги, ожидаемый и фактический результат.
- Сообщение из «Детали файла → Показать техническую причину».

**Удаляй из отчётов cookies, токены, пароли и приватные ссылки.**

## Разработка

1. Сделай форк и создай отдельную ветку.
2. Соблюдай существующую Kotlin/Compose-архитектуру.
3. Добавляй unit-тесты для URL, форматов и обработки ошибок.
4. Прогоняй проверки:

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

5. Открой Pull Request и кратко объясни изменения.

## Правила

- Никакой рекламы, искусственных ограничений и скрытой телеметрии.
- Никакой работы с DRM или украденными учётными данными.
- Не обещай скачивание каждого ролика: доступность зависит от yt-dlp и сайта.
- Пользовательский интерфейс должен оставаться понятным и доступным.
- Соблюдай лицензии используемых библиотек.

## Подпись

CI-артефакты используют временный debug-ключ. Для стабильных публичных релизов требуется постоянный release-ключ вне репозитория.
